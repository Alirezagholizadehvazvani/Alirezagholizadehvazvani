## Selected projects

### [Industrial Motor Monitor](https://github.com/Alirezagholizadehvazvani/industrial-motor-monitor)

An ESP32 monitoring and protection prototype developed primarily for Jahan Pump Co.'s three-phase pump products.

- C++/Arduino firmware for current and voltage acquisition, fault checks, OLED status, and a relay interface.
- SCT-013 current transformers, ZMPT101B voltage modules, and an ADS1115 ADC.
- Schematics, build photographs, assembly notes, and wiring and noise troubleshooting records.

The public repository contains the work permitted for publication, including initial bench tests and documented measurement limitations. These records do not establish validated protection performance on company products.

### [Gas Cylinder Filling Safety](https://github.com/Alirezagholizadehvazvani/gas-cylinder-filling-safety)

A Python simulation of safety-oriented control logic for oxygen/nitrogen cylinder filling, with pressure monitoring, fault lockout, valve feedback checks, and explicit reset behavior.

The project includes regression tests, fault-injection scenarios, and requirements-to-test traceability. It is a digital logic prototype.

### [Predictive Maintenance](https://github.com/Alirezagholizadehvazvani/predictive-maintenance)

A Python pipeline combining synthetic sensor data, preprocessing, Random Forest classification, and Flask/Streamlit dashboards. The project demonstrates a monitoring workflow using synthetic data.
