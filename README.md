# Alireza Gholizadeh Vazvani

Software engineer with hands-on industrial experience, focused on building reliable software for real industrial environments.

Before focusing on software, I worked as a technician in industrial companies. That experience gave me a practical understanding of how equipment fails, what operators actually need, and why many software systems fail in the field. I now design software with that reality in mind — clean architecture, strong simulation, and systems that can move from software validation to real industrial use.

---

### Featured Projects

**[Motor Health Monitor](https://github.com/Alirezagholizadehvazvani/motor-health-monitor)**  
Software foundation for industrial 3-phase motor and pump protection.  
Built with a clean Hardware Abstraction Layer and full simulation of critical failure modes (phase imbalance and dry-run). Designed so the same logic can later run on real hardware with minimal changes.

**[Predictive Maintenance Pipeline](https://github.com/Alirezagholizadehvazvani/predictive-maintenance)**  
End-to-end machine learning system for industrial equipment monitoring.  
Covers synthetic data generation, model training, and real-time dashboards. Demonstrates a complete software pipeline from data to actionable insights.

**[Gas Cylinder Filling Safety System](https://github.com/Alirezagholizadehvazvani/gas-cylinder-filling-safety)**  
Digital simulation of a fail-safe control system for high-pressure gas cylinder filling.  
Focuses on safety logic, automated fault injection, and requirements traceability — core concerns in industrial software.
